# /pull-back-reveal

Крупний план, потім камера відʼїжджає — і ти всередині Claude Code.

## Що потрібно
- Вертикальне відео з тобою (9:16)

## Найкращий кадр
Крупний план.

## Ефект
Починаємо з мого відео на весь кадр, потім різкий відʼїзд камери з розмиттям руху: відео виявляється превʼю всередині вікна Claude Code. Ліворуч у списку по черзі ставляться галочки: «Transcribed», «Cut silences», «Added captions», «Rendered 4K».

Фігурні дужки `{…}` — те, що підставляє користувач. Якщо він їх не дав — спитай або запропонуй варіант.

## Як зібрати
1. Візьми відео користувача (якщо шлях не вказано — спитай).
2. Підготуй кліп: `~/.claude/skills/commands-base/scripts/prep.sh <відео> ./pull-back-reveal-build` — кадри, вирізка, рамки обличчя, звук і шаблон.
3. Збери ефект з розділу «Ефект» у `./pull-back-reveal-build/scene.js` на рушії `engine.js` (`Video`, `Cut`, `Cut(…, true)`, `FB(t)`, `CHIN`).
4. Шари: `Video` → що за тобою → `Cut` → що перед тілом → `Cut(…, true)` останнім. Обличчя нічим не перекривай: елементи перед тобою — нижче `CHIN + 60` або збоку.
5. Перевір 3 кадри: `node ~/.claude/skills/commands-base/tools/render.mjs ./pull-back-reveal-build/check "file://$PWD/pull-back-reveal-build/index.html" --w 1080 --h 1920 --times 0.5,1.5,2.5` і покажи їх користувачу.
6. Рендер: `~/.claude/skills/commands-base/scripts/encode.sh ./pull-back-reveal-build ./pull-back-reveal.mp4`.
