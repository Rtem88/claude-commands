# /prompt-bar

Рядок промпту пливе над головою і сам відправляється.

## Що потрібно
- Вертикальне відео з тобою (9:16)
- Текст промпту

## Найкращий кадр
Над головою вільно.

## Ефект
Над моєю головою — світлий рядок вводу. У ньому друкується «{промпт}», кнопка ↑ стає помаранчевою і натискається, рядок злітає вгору.

Фігурні дужки `{…}` — те, що підставляє користувач. Якщо він їх не дав — спитай або запропонуй варіант.

## Як зібрати
1. Візьми відео користувача (якщо шлях не вказано — спитай).
2. Підготуй кліп: `~/.claude/skills/commands-base/scripts/prep.sh <відео> ./prompt-bar-build` — кадри, вирізка, рамки обличчя, звук і шаблон.
3. Збери ефект з розділу «Ефект» у `./prompt-bar-build/scene.js` на рушії `engine.js` (`Video`, `Cut`, `Cut(…, true)`, `FB(t)`, `CHIN`).
4. Шари: `Video` → що за тобою → `Cut` → що перед тілом → `Cut(…, true)` останнім. Обличчя нічим не перекривай: елементи перед тобою — нижче `CHIN + 60` або збоку.
5. Перевір 3 кадри: `node ~/.claude/skills/commands-base/tools/render.mjs ./prompt-bar-build/check "file://$PWD/prompt-bar-build/index.html" --w 1080 --h 1920 --times 0.5,1.5,2.5` і покажи їх користувачу.
6. Рендер: `~/.claude/skills/commands-base/scripts/encode.sh ./prompt-bar-build ./prompt-bar.mp4`.

## Прямий промпт
Якщо скіли не встановлені, цей текст можна вставити в Claude Code напряму:

```
Зроби на моєму відео ефект «prompt-bar».

Над моєю головою — світлий рядок вводу. У ньому друкується «{промпт}», кнопка ↑ стає помаранчевою і натискається, рядок злітає вгору.

Відео: {мій файл, наприклад video.mp4}. Виріж мене з фону, щоб ефект міг стояти за мною; моє обличчя ніколи нічим не перекривай. Формат 1080×1920, 30 fps, MP4 з оригінальним звуком. Спершу покажи мені 3 ключові кадри, потім рендер.
```
