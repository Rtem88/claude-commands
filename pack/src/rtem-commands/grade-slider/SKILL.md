# /grade-slider

Повзунок «до / після» кольорокорекції проходить по тобі.

## Що потрібно
- Вертикальне відео з тобою (9:16)

## Найкращий кадр
Будь-який план.

## Ефект
Вертикальний повзунок проходить по кадру: ліворуч — сирий плаский кадр, праворуч — теплий кінематографічний грейд. Повзунок зупиняється, вертається і йде до кінця.

Фігурні дужки `{…}` — те, що підставляє користувач. Якщо він їх не дав — спитай або запропонуй варіант.

## Як зібрати
1. Візьми відео користувача (якщо шлях не вказано — спитай).
2. Підготуй кліп: `~/.claude/skills/commands-base/scripts/prep.sh <відео> ./grade-slider-build` — кадри, вирізка, рамки обличчя, звук і шаблон.
3. Збери ефект з розділу «Ефект» у `./grade-slider-build/scene.js` на рушії `engine.js` (`Video`, `Cut`, `Cut(…, true)`, `FB(t)`, `CHIN`).
4. Шари: `Video` → що за тобою → `Cut` → що перед тілом → `Cut(…, true)` останнім. Обличчя нічим не перекривай: елементи перед тобою — нижче `CHIN + 60` або збоку.
5. Перевір 3 кадри: `node ~/.claude/skills/commands-base/tools/render.mjs ./grade-slider-build/check "file://$PWD/grade-slider-build/index.html" --w 1080 --h 1920 --times 0.5,1.5,2.5` і покажи їх користувачу.
6. Рендер: `~/.claude/skills/commands-base/scripts/encode.sh ./grade-slider-build ./grade-slider.mp4`.
