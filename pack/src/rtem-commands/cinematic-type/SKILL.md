# /cinematic-type

Кольорові картки на весь екран з великою курсивною фразою і рядком, що зʼявляється по слову.

## Що потрібно
- 2–3 фрази

## Найкращий кадр
Відео не потрібне.

## Ефект
Три картки на весь екран: помаранчева «{фраза 1}», чорна «{фраза 2}», жовта «{фраза 3}». Велика фраза курсивом із засічками зʼявляється з розмиття, під нею рядок по одному слову. Перехід — шторкою знизу.

Фігурні дужки `{…}` — те, що підставляє користувач. Якщо він їх не дав — спитай або запропонуй варіант.

## Як зібрати
1. Створи `./cinematic-type-build`: скопіюй туди `~/.claude/skills/commands-base/template/*` і створи `footage/clip.js` з `window.CLIP={n:<кадри>,fps:30}; window.FACES=[[340,700,400,400]];` (відео не потрібне).
2. Збери ефект з розділу «Ефект» у `scene.js` (без `Video` і `Cut`).
3. Перевір 3 кадри: `node ~/.claude/skills/commands-base/tools/render.mjs ./cinematic-type-build/check "file://$PWD/cinematic-type-build/index.html" --w 1080 --h 1920 --times 0.5,1.5,2.5` і покажи їх користувачу.
4. Рендер: `~/.claude/skills/commands-base/scripts/encode.sh ./cinematic-type-build ./cinematic-type.mp4`.

```

Формат 1080×1920, 30 fps, MP4. Спершу покажи мені 3 ключові кадри, потім рендер.
```
