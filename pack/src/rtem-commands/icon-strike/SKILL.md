# /icon-strike

Старі програми для монтажу закреслюються одна за одною.

## Що потрібно
- Вертикальне відео з тобою (9:16)
- Іконки програм

## Найкращий кадр
Один бік кадру вільний.

## Ефект
Збоку від мене стовпчиком стоять іконки {програми}. По черзі через кожну проходить червона лінія, іконка сірішає.

Фігурні дужки `{…}` — те, що підставляє користувач. Якщо він їх не дав — спитай або запропонуй варіант.

## Як зібрати
1. Візьми відео користувача (якщо шлях не вказано — спитай).
2. Підготуй кліп: `~/.claude/skills/commands-base/scripts/prep.sh <відео> ./icon-strike-build` — кадри, вирізка, рамки обличчя, звук і шаблон.
3. Збери ефект з розділу «Ефект» у `./icon-strike-build/scene.js` на рушії `engine.js` (`Video`, `Cut`, `Cut(…, true)`, `FB(t)`, `CHIN`).
4. Шари: `Video` → що за тобою → `Cut` → що перед тілом → `Cut(…, true)` останнім. Обличчя нічим не перекривай: елементи перед тобою — нижче `CHIN + 60` або збоку.
5. Перевір 3 кадри: `node ~/.claude/skills/commands-base/tools/render.mjs ./icon-strike-build/check "file://$PWD/icon-strike-build/index.html" --w 1080 --h 1920 --times 0.5,1.5,2.5` і покажи їх користувачу.
6. Рендер: `~/.claude/skills/commands-base/scripts/encode.sh ./icon-strike-build ./icon-strike.mp4`.
