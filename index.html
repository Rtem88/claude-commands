README

Як встановити і список усіх команд.

Потрібно лише кілька? Натисни «Вибрати кілька» і завантаж тільки їх.

З рілсу

Натисни, щоб побачити, що потрібно, і скопіювати промпт.

Налаштування за 2 хвилини

Один раз. Далі кожна команда просто працює.

1

Встанови інструменти

Claude Code, Node 18+, ffmpeg і Google Chrome. Вирізка працює на Apple Vision, тож потрібен macOS 12+ з Xcode Command Line Tools.

2

Встанови набір

Розпакуй архів і скопіюй усі папки, разом із commands-base, у ~/.claude/skills/

3

Запусти команду

Відкрий Claude Code у папці з відео і напиши /orbit візьми моє відео video.mp4

4

Зніми під ефект

Вертикально, камера нерухома, навколо голови трохи місця. У кожній команді написано, який кадр їй підходить.

Без скілів? У кожної команди є прямий промпт — його можна просто вставити в Claude Code.
